# Dipmala.dev Portfolio

Premium responsive personal portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` with VS Code Live Server.

## Before publishing
1. Replace project `link` values in `js/script.js`.
2. Add project screenshots to `assets/images/` and set their paths in `projects`.
3. Add certificate images/PDFs and update the `certificates` array.
4. Add your real GitHub, LinkedIn and email links.
5. Put your resume at `assets/resume/Dipmala-Resume.pdf` and update the Resume button.

## Structure
- `index.html`
- `css/style.css`
- `js/script.js`
- `assets/images/profile.png`
- `assets/certificates/`
